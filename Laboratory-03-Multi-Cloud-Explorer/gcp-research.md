# Checkpoint 2 - Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is a suite of cloud services. Google runs it on its internal infrastructure.

## Global Infrastructure
GCP spans multiple regions globally. Each region contains zones. A global fiber network connects them.

## Cloud Management Console
The Google Cloud Console provides a web interface. You manage your GCP projects here. It includes tools for billing and API management.

## Core Services
1. **Google Compute Engine:** Offers customizable virtual machines.
2. **Google Cloud Storage:** Delivers secure object storage.
3. **Google Kubernetes Engine (GKE):** Manages containerized applications.
4. **BigQuery:** Analyzes large datasets quickly.

## Advantages
1. Excellent machine tools.
2. High-performance global network.
3. Strong data analytics capabilities.

## Typical Enterprise Use Cases
Businesses run complex data analytics on GCP. They develop machine learning models. They manage massive container deployments.
