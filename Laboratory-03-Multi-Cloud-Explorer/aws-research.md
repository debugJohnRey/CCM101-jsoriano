# Checkpoint 2 - Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a cloud platform. Amazon provides it. It offers compute power, database storage, and content delivery.

## Global Infrastructure
AWS operates in multiple regions worldwide. Each region has availability zones. These zones have distinct data centers. This design ensures high availability.

## Cloud Management Console
The AWS Management Console is a web interface. You use it to manage your AWS resources. It provides access to billing, monitoring, and security tools.

## Core Services
1. **Amazon EC2:** Provides virtual servers.
2. **Amazon S3:** Stores objects and files.
3. **Amazon RDS:** Manages relational databases.
4. **AWS Lambda:** Runs code without provisioning servers.

## Advantages
1. Large ecosystem of services.
2. High reliability and uptime.
3. Global reach.

## Typical Enterprise Use Cases
Companies use AWS for web hosting. They migrate legacy applications to it. Enterprises build data lakes on AWS.
