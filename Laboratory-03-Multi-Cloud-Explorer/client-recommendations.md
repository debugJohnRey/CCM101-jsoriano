# Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS offer a flexible pay-as-you-go pricing models for startup. This model keep initial cost low. The platforms scale easily to handle rapid user growths when they expand in the future. AWS feature a broad ecosystem to supports mobile application.

**Recommended Services:** Amazon EC2, Amazon S3, and Amazon RDS.

## Client B – University
**Recommended Platform:** Microsoft Azure

**Explanation:** Microsoft Azure integrate natively with existing Microsoft tool. The platform support seamless migration to the cloud. Azure provide strong hybrid cloud capabilities for large organizations that want to keeps their old systems. This native integrations reduce frictions during security review.

**Recommended Services:** Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage.

## Client C – AI Research Company
**Recommended Platform:** Google Cloud Platform (GCP)

**Explanation:** GCP lead the market in high-performance computing and artificial intelligence. The platform offer specialized Processing Units to trains models. Google provide superior tool for large machine learning workflows which require lot of compute power. GCP represent the top choice for AI research organization.

**Recommended Services:** Vertex AI, Google Compute Engine, and Google Cloud Storage.

## Client D – Global E-Commerce Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS maintain the largest global infrastructure with numerous availability zone. This coverages ensure maximum geographical distribution and enterprise-level resilience for global company. The platform manage demand peaks effectively with rapid scaling. 

**Recommended Services:** Amazon EC2, Amazon CloudFront, and Amazon RDS.

## Checkpoint 6 – Multi-Cloud Decision Matrix 

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | Amazon Web Services (AWS) | AWS offer flexible pricing that are cheap for small teams. Startups can builds their apps fast without spending too much money upfront. |
| **Enterprise Organization** | Amazon Web Services (AWS) | AWS have the largest global infrastructure. Big enterprise need this scale so their systems doesn't crashes during peak demands. |
| **Microsoft Environment** | Microsoft Azure | Azure integrate perfectly with Windows tool. If a company use Active Directory already, it save them lot of times. |
| **AI / Machine Learning** | Google Cloud Platform (GCP) | GCP provide the best tools for artificial intelligences. It have specialized processors that trains machine learning models very fast. |
| **Kubernetes Deployment** | Google Cloud Platform (GCP) | Google original created Kubernetes so GCP have the best supports for it. It make managing containers deployments much easier. |
| **Global Web Application** | Amazon Web Services (AWS) | AWS maintain many availability zone all over the world. This ensure your web apps stays online and load fasts for users everywhere. |
