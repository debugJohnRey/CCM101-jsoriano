# Checkpoint 2 - Microsoft Azure Research

## Brief Overview
Microsoft Azure is a public cloud platform. It offers infrastructure and platform services. 

## Global Infrastructure
Azure has a massive global network. Microsoft places data centers in regions around the world. These regions connect through a dedicated network.

## Cloud Management Console
The Azure portal is a single web console. You build, manage, and monitor your apps here. You can customize the dashboard.

## Core Services
1. **Azure Virtual Machines:** Hosts Windows or Linux servers.
2. **Azure Blob Storage:** Stores massive amounts of unstructured data.
3. **Azure SQL Database:** Provides a managed database service.
4. **Azure App Service:** Hosts web apps and APIs.

## Advantages
1. Strong integration with Microsoft products.
2. Robust hybrid cloud features.
3. Comprehensive compliance coverage.

## Typical Enterprise Use Cases
Enterprises use Azure for identity management. They run Windows Server workloads. They build hybrid cloud environments.
