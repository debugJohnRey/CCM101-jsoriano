## Questions and Answers

**1. Which cloud provider offers the broadest range of services?**
AWS offer the most broad range of services. It provide over 200 different service in many category. AWS launch early and expand its catalog to stay the market leader.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure integrate best with Microsoft technologies. Enterprise can seamlessly runs Windows Server and Active Directory on it. It also support SQL Server workloads well.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform provide the most strong tools for Artificial Intelligence. GCP also offer deep integration for container orchestrations. Google original created Kubernetes.

**4. Which cloud platform would you personally choose and why?**
I would chooses Google Cloud Platform. Its strong focus on artificial intelligence create a ideal environment. You can use it to builds AI image generation workflows.
