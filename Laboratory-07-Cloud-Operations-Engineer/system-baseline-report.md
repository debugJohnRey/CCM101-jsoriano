# Checkpoint 2 - Establish a Host System Baseline

## Resource Metrics
* **Total RAM Available on the Server:** 1.9Gi total (1.4Gi available)
* **Total Storage Capacity of the Root (/) File System:** 19G (13G available)

## Importance of Disk Space Monitoring
Checking disk space before a massive traffic surge is critical because web servers write a log entry for every visitor, and a full disk will crash the server.
