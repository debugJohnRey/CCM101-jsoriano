# Checkpoint 2 - Research: Virtual Machines vs. Containers
| Category | Virtual Machines (VMs) | Containers |
| :--- | :--- | :--- |
| **Architecture** | Guest OS | Shared Host OS |
| **Boot Time** | Minutes | Seconds |
| **Resource Efficiency** | Heavy/High RAM | Lightweight/Low RAM |
| **Isolation Level** | Hardware-level | Process-level |

## Summary
CContainers boot in seconds. They share the host operating system instead of booting a complete guest system, which stops RAM waste. This lightweight design runs web applications fast. You gain high resource efficiency.
