## Linux Commands Used

| Command | What it does |
|---|---|
| `adduser` | Creates a new user account. |
| `su` | Switches to the new user account. |
| `whoami` | Prints the current username. |
| `pwd` | Prints the current working folder. |
| `hostname` | Prints the computer name. |
| `cat /etc/os-release` | Shows the Linux distribution details. |
| `uname -r` | Prints the kernel version. |
| `lscpu` | Shows the CPU details. |
| `free -h` | Shows total and used memory. |
| `df -h` | Shows available disk space. |
| `mkdir` | Makes new folders. |
| `touch` | Creates a new empty file. |
| `nano` | Opens a text editor to write inside files. |
| `git clone` | Downloads the GitHub repository to the workspace. |
| `git add` | Prepares files to save. |
| `git commit -m` | Saves file changes with a message. |
| `git push` | Uploads files to GitHub. |
