# Checkpoint 7 – Mission Reflection 

Networking is the most important cloud infrastructure component. The cloud relies entirely on remote access. Users cannot reach servers without a network. A network connects compute, storage, and identity systems together. It links databases to web applications. It makes the entire cloud work as one single unit. The fastest processor means nothing without a solid connection.

Linux acts as the foundation for most of these cloud servers. It manages server hardware efficiently. The operating system handles heavy computing workloads well. Linux provides powerful command-line tools. These tools let engineers control the system quickly. Linux is also open-source software. Cloud providers do not pay licensing fees to use it. They pass these exact savings to their users. This keeps cloud computing costs low.

Technical documentation acts as a clear blueprint before engineers deploy infrastructure. Teams need a solid plan before they build anything. This prevents costly mistakes during the setup phase. Good documents align the whole team. They serve as a guide for future system updates. Documentation also helps teams solve problems faster when systems fail.

I learned to write professional technical reports using Markdown formatting. I mapped a simple cloud architecture using a visual diagramming tool. I also researched core services across AWS, Azure, and Google Cloud. I compared their computing and storage options.
