# Checkpoint 4 – Research the Major Cloud Providers

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
| :--- | :--- | :--- | :--- |
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS offers the broadest range of services. It launched first and holds the largest market share. This early start let Amazon build a massive service catalog.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
I recommend Microsoft Azure for organizations using Microsoft products. Azure connects directly with Windows, Office 365, and Active Directory. This connection makes management easy and speeds up setup.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform leads in AI, ML, and Kubernetes. Google created Kubernetes and offers the best support for it. The company also builds powerful machine learning tools.

**4. What similarities did you observe among the three cloud providers?**
All three providers offer the same core infrastructure categories. They charge users with a pay-as-you-go pricing model. They run global data centers to keep services online.
