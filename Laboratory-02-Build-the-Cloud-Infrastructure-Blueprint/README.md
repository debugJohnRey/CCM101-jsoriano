# Checkpoint 6 – Technical Documentation 

## Mission Overview
This laboratory investigates cloud infrastructure components. The mission requires identifying how compute, storage, networking, and identity services work together. I documented these findings to simulate preparing technical client documentation.

## Objectives
* Explain major cloud infrastructure components.
* Investigate hardware and software resources in a Linux environment.
* Differentiate compute, storage, networking, and identity resources.
* Interpret the relationships between these cloud components.
* Create professional technical documentation using Markdown.
* Build a structured GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components
* **Compute Resources:** Processors and RAM run applications and handle data. 
* **Storage Resources:** Hard drives and block storage save files permanently.
* **Networking Resources:** IP addresses and virtual networks connect systems together.
* **Operating System:** The system software manages the hardware and runs cloud applications.

## Linux Commands Executed
* `cat /etc/os-release`: Shows operating system details.
* `uname -r`: Prints the kernel version.
* `lscpu`: Lists CPU hardware details.
* `nproc`: Counts the number of processing cores.
* `free -h`: Displays available and used RAM.
* `df -h`: Shows disk storage capacity.
* `findmnt`: Lists active connected drives.
* `hostname`: Prints the computer network name.
* `ip addr`: Shows network interface details and IP addresses.
