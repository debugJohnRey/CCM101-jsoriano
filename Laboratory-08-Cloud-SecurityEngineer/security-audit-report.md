# Checkpoint 2 - Research: Security Best Practices

**The Principle of Least Privilege (PoLP):**
Give users only the access they need to do their jobs. This limits damage if someone steals an account.

**Attack Surface:**
This is the total number of weak spots a hacker can target on a virtual machine. A smaller attack surface means fewer entry points for attackers.

**Default Deny Policy:**
Block all traffic first. Then, allow only trusted traffic. This automatically stops unknown threats.
