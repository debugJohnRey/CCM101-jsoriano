# Checkpoint 7 - Mission Reflection

A host-based firewall add a critical second layer of defense. It acts like a personal guard for the operating system that blocks unauthorized traffic right at the server level. The server stays safe even if hackers breach the main network, which means this strategy creates a strong defense in depth. A single failure will not easily exposed the whole system.

Open network ports act exactly like an unlocked doors. Attackers are constantly scanning these ports so they can find ways to get inside our system. Closing unused ports removes these entry points. This action shrink the attack surface. Because a smaller attack surface leaves fewer targets for hackers, administrators must carefully control ports to keep all threats out.

A database hold highly sensitive records and data. Leaving a database port open to the internet invites constant danger from hackers who launch automated attacks from anywhere. They steal or destroy critical business data. Administrators must restrict database access to only trusted internal servers. This isolates the valuable information from public threat.

This mission completely change my view on server deployment. I saw the dangers of default settings. When a brand new server connects to the internet without protection, bots scan for those exposed machines constantly. Security requires immediate action. Engineers must secure the systems before they deploy applications, because waiting even just a few minutes can causes data breaches.
