## Checkpoint 5 - Technical Documentation 

# Mission Overview
This mission deploys a containerized Object Storage server. The project uses MinIO to create an S3-compatible environment. The work includes creating a storage bucket and uploading data over the web.

# Objectives
* Deploy a MinIO object storage server using Docker.
* Compare block, file, and object storage types.
* Access a cloud service via port forwarding.
* Create a storage bucket and upload files.
* Document technical configurations using Markdown.

# Tools Used
* Docker
* MinIO
* KillerCoda Ubuntu Playground
* GitHub

# Skills Learned
