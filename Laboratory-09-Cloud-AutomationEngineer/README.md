# Checkpoint 6 - Technical Documentation 

## Mission Overview
I stepped into the role of a Cloud Automation Engineer at CloudNova Technologies to eliminate human error in the backup process[cite: 1, 2]. I created a dummy application directory, wrote a Bash script to automatically compress and back up that data, and scheduled the script to run autonomously every night at 2:00 AM using the Linux Cron scheduler[cite: 1, 2].

## Objectives
* Understand the fundamental syntax of a Bash shell script, including variables and basic commands[cite: 1].
* Use a command-line text editor (nano) to write and save executable scripts[cite: 1].
* Modify Linux file permissions using the chmod command[cite: 1].
* Understand task scheduling and the syntax of a Linux crontab[cite: 1].
* Document automation code and Cron job configurations using Markdown[cite: 1].
* Complete the final chapter of the GitHub Cloud Computing Portfolio[cite: 1].
