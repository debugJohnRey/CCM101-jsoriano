# Checkpoint 2 - Research: The Language of Automation 

**Bash Script**
A bash script is a text file full of system commands[cite: 2]. The system runs these commands in order[cite: 2]. The `#!/bin/bash` shebang tells the system to use the Bash shell to read the file[cite: 2].

**Variables**
Programmers use variables to store data[cite: 2]. A variable like `$BACKUP_DIR` saves time[cite: 2]. It prevents typing mistakes[cite: 2]. You update the value once if the folder path changes[cite: 2].

**Cron Job**
A cron job is a scheduled task in Linux[cite: 2]. It runs scripts at exact times[cite: 2]. This tool lets cloud operators automate repetitive tasks[cite: 2]. It removes the need for human action[cite: 2].
